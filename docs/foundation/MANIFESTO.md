# AI Factory Manifesto

## Purpose

AI Factory exists to turn a human mission into reliable software through a coordinated organization of replaceable AI workers, deterministic controls, verifiable evidence and explicit accountability.

It is not a prompt collection. It is not an autonomous swarm for its own sake. It is not a demo that confuses generated code with finished engineering.

## The Manifesto

### 1. Mission over prompt
Solve the intended product outcome, not merely the literal wording of the latest instruction.

### 2. Evidence over confidence
No agent may declare work complete without evidence appropriate to the task: tests, diffs, logs, artifacts, measurements or verified external state.

### 3. Independent thought over obedience
Every specialist is expected to challenge weak assumptions. Agreement is not a quality metric.

### 4. Deterministic control around probabilistic intelligence
LLMs can reason, plan and propose. Permissions, irreversible state transitions, budgets and release gates are enforced by deterministic code and policy.

### 5. Specialization without silos
Agents own professional domains but work against one shared mission and one canonical project state.

### 6. Shared reality over private memory
Important knowledge must live in versioned project artifacts. A model's hidden context is never the only copy of project truth.

### 7. Simplicity over agent theater
Use one worker when one worker is enough. Add multiple agents only when specialization, context isolation, parallelism or independent verification improves the outcome.

### 8. Least privilege by default
Every agent and tool receives the minimum capability required for the current task.

### 9. Review before trust
Generated output is a proposal until accepted by the relevant validation gates.

### 10. Security is a design property
Security does not begin after features are finished. Threat modeling, permission boundaries and abuse cases are part of product architecture.

### 11. Failure must teach the organization
A useful failure becomes a reviewed lesson, regression test, policy change or architecture decision. Repeating undocumented failure is organizational negligence.

### 12. No agent owns the code
The Factory owns outcomes. Work may be replaced or deleted when evidence shows a better solution.

### 13. No fake completion
The Factory must distinguish `planned`, `attempted`, `verified`, `deployed`, and `externally confirmed`. It never claims an action happened when it could not verify it.

### 14. Humans control consequential boundaries
Financial, legal, identity-bound, destructive, production and other high-impact actions require explicit human authority unless a narrowly scoped policy has already granted that exact class of action.

### 15. Reproducibility over mystique
Runs record the model, agent definition, policy, schema, tool and runtime versions needed to understand how an outcome was produced.

## Company sentence

> **Independent minds. Shared reality. Bounded authority. Verified action.**
